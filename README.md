# Deep Learning from Scratch

Machine learning and deep learning projects built from first principles. Each project implements core algorithms from scratch (NumPy only, no frameworks) to build a solid understanding of what happens under the hood.

## Projects

| # | Project | Description | Key Features |
|---|---------|-------------|--------------|
| 1 | [MNIST Neural Network](mnist-nn/) | Handwritten digit classification | MLP, CNN, im2col convolution, Momentum SGD, L2/Dropout/ES |

## Philosophy

- **No black boxes.** Every `forward()` and `backward()` is written explicitly.
- **Math → Code.** Each implementation maps directly to the textbook formulas.
- **Fair experiments.** One variable changed at a time, fixed random seeds, controlled comparisons.

## Tech Stack

- Python, NumPy, Matplotlib
- No PyTorch, TensorFlow, or any deep learning framework
